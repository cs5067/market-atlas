# Source provenance

The eight modules under `research/` were selected from the existing personal trading project. They preserve the original algorithm implementations and sibling imports. This is a focused publication snapshot rather than the complete private development directory.

[source-manifest.json](source-manifest.json) records the original filename, original SHA-256, published SHA-256 and each publication adaptation. Filenames are retained to make the module relationships clear. Absolute personal paths are not included.

Publication adaptations are limited to requiring an explicit tick source directory, clarifying research claims in introductory comments, and replacing conversational report wording. No model result, historical return or market dataset has been added. The synthetic demo and correctness tests were added for this public edition; they are separate from the original strategy implementation.

Source code, documentation and tests are published here. Credentials, account and trade records, chat exports, generated datasets, screenshots and the live execution system are excluded.
